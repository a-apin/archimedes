# `backend/requirements.txt` (Docker / CI) and the `pip:` block of
# `environment.yml` (local conda dev) pull it in with `-r`, so a Dependabot bump

# Deliberately carries NO index directive. The pytorch CPU wheel index lives in
# `backend/requirements.txt` and only there: pulling it onto the path

# lose MPS on Apple Silicon. Do not add an index directive, `torch`, or
# `sentence-transformers` to this file — `backend/tests/
# test_env_requirements_alignment.py` fails the build if you do.
